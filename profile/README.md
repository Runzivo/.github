# Runzivo

Runzivo is building fast, secure, scalable CI/CD compute and managed runners for software teams. V1 starts with Linux x64 runners for GitHub Actions.

Faster CI. Less waiting.

## Planned V1 Early Access

- GitHub Actions
- Linux x64 runners
- Managed runner access for approved organizations

```yaml
jobs:
  test:
    runs-on: runzivo-linux-x64
```

## Planned Early Access flow

1. Email [hello@runzivo.dev](mailto:hello@runzivo.dev) to request access.
2. After approval, install the Runzivo GitHub App for selected repositories.
3. After installation, update a GitHub Actions job to use `runs-on: runzivo-linux-x64`.
